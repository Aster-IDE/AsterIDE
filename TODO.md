- Add Indictors:
	- Active File
	- Modified File
	- Git Indictors:
		- Untracked
		- Unstaged / Staged Changes
		- Submodule
		- Deleted

		- Emphasized

- SCM Support for Git, Mercurial & Jujutsu
- Multi Language Integrated LSP
- Proper Syntax Highlighting for over 30 Programming Languages
- Setings:
	- Ability to Hide and Unhide hidden files
	- Line Wrap
	- Display Line numbers
	- Minimap
	- Linting
	- Discord RPC (https://github.com/playfairs/AsterIDE-Discord-Presence)
	- Corner Roundness
	- Font Family
	- Font Size
	- Line Height
	- Tab Spaces
	- Tab Size
	- Vim & Helix Mode
	- Ask before closing
	- Prompt file saving before quitting while unsaved files exist
	- Auto Save:
		- Audo Save
		- Auto Save on Focus Lost
		- Auto Save before closing a tab
